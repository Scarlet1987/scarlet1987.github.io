№ 1 — DAY ONE

"Did it arrive broken — or did the first patch become the real launch?" The № 1 gripe at any big launch gets the first panel. Alice doesn't ship until it's stable, and every update reports here, four questions, in order:

1

What size was the patch? Size is the first honesty.

2

What did it fix? Named the way the report came in.

3

What did it make worse? "Nothing" has to be looked for, not assumed — regressions get the same size type as fixes.

4

How does the rest of the software function? What changed underneath; what stayed exactly where you left it.

EXAMPLE — the format, from a real fix: 1 · ~37 MB, the whole package (Alice ships full installers, not deltas). 2 · The "unknown VRAM" card on AMD — it now reads what the startup audit found. 3 · Nothing worse; the VRAM bar says "unavailable" instead of spinning forever, on purpose. 4 · Nothing else moved.

The scale

Base program today: ~37 MB. Warning line: 500 MB — crossing it gets reported here, with what's driving the growth. Hard cap: 2 GB, never. Models and your data never count; they're yours and live separately. Checked weekly.

The big gripes — pre-labeled

"I can't find it." Nothing hides here — if you hunted, it's a bug. Tell us what you were looking for.

"There's nothing here." By design: the vessel ships empty, create buttons at the starting line.

"Image generation doesn't work." True, and labeled in the app: the engine is in development. No fake buttons.

"It runs slow." Baseline is an RX 580 / 8GB. Engine resources shows your machine live — report GPU, RAM, where it dragged.

"Do I have to set it up first?" Open it and start. The wizard asks hardware + downloads only.
